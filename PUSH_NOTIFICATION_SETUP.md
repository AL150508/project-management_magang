## 🔄 Push Notification Flow

```
1. User clicks "Aktifkan Notifikasi" button
   ↓
2. Browser requests notification permission
   ↓
3. User grants permission
   ↓
4. Service Worker subscribes to push service
   ↓
5. Subscription token saved to database (notification_tokens table)
   ↓
6. Event occurs (logbook submitted, magang registered, etc.)
   ↓
7. Backend calls /api/test-push-all
   ↓
8. API fetches ALL tokens from database (no role filter)
   ↓
9. API sends push notification via web-push library
   ↓
10. Windows Notification Service delivers to browser
    ↓
11. Service Worker (sw-push.js) receives push event
    ↓
12. Service Worker shows notification in Windows Action Center
```

## 🚀 How to Send Push Notifications

### ✅ CORRECT Way (Current Implementation):

```javascript
// Send push to ALL subscribed devices
fetch('/api/test-push-all', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    title: '📖 Logbook Baru',
    body: 'fuji mengirim logbook: okee gas...',
    icon: '/icons/icon-192x192.png',
    url: '/logbook'
  })
})
.then(res => res.json())
.then(data => console.log('✅ Push sent to', data.sent, 'device(s)'))
.catch(err => console.error('❌ Error:', err))
```

### ❌ WRONG Way (DO NOT USE):

```javascript
// This will filter by role and may send to 0 devices
sendPushToRole('guru', {
  title: 'Notification',
  body: 'Message',
  url: '/'
})
```

## 🐛 Troubleshooting

### Push notification not appearing?

1. **Check browser console:**
   ```
   Expected logs:
   ✅ Push sent to X device(s)
   [SW Push] Push event received
   [SW Push] Parsed JSON data: {...}
   [SW Push] Showing notification
   ✅ Notification shown successfully
   ```

2. **If no `[SW Push]` logs:**
   - Service Worker might not be running
   - Go to: DevTools → Application → Service Workers
   - Check if sw-push.js is active
   - Click "Push" button to test manually

3. **If error 401:**
   - Token might be expired or invalid
   - Clear subscription and re-subscribe:
   ```javascript
   // In console
   navigator.serviceWorker.ready.then(async (reg) => {
     const sub = await reg.pushManager.getSubscription()
     if (sub) await sub.unsubscribe()
     location.reload()
   })
   ```

4. **If "Push sent to 0 device(s)":**
   - No subscriptions in database
   - User needs to click "Aktifkan Notifikasi" first
   - Check `notification_tokens` table in Supabase

### ALWAYS:
- ✅ Use `/api/test-push-all` for sending push notifications
- ✅ Send to ALL subscribed devices (no role filter)
- ✅ Include clear & informative title and body
- ✅ Test push notifications after any changes
- ✅ Delete old tokens before inserting new subscription

## 📊 Database Schema

### Table: `notification_tokens`

```sql
- id: uuid (primary key)
- user_id: uuid (foreign key to users)
- device_token: text (JSON string of PushSubscription)
- platform: text ('web')
- created_at: timestamp
- updated_at: timestamp
```
