# Icons Folder untuk PWA

Folder ini berisi icon aplikasi untuk Progressive Web App (PWA).

## Icon yang Diperlukan

Untuk PWA berfungsi dengan baik, Anda perlu menyediakan icon berikut:

### Icon Wajib:
- `icon-192x192.png` - Icon 192x192 pixels (untuk Android home screen)
- `icon-512x512.png` - Icon 512x512 pixels (untuk splash screen dan Android)

### Rekomendasi Format:
- Format: PNG dengan transparansi (jika diperlukan)
- Background: Transparan atau solid color
- Style: Sesuai dengan brand aplikasi

## Cara Membuat Icon

### Opsi 1: Online Tool
1. Gunakan tool seperti [PWA Asset Generator](https://github.com/onderceylan/pwa-asset-generator)
2. Upload logo/icon Anda
3. Generate icon dalam berbagai ukuran
4. Download dan simpan di folder ini

### Opsi 2: Manual
1. Buat icon dengan ukuran minimal 512x512 pixels
2. Export sebagai PNG
3. Resize ke 192x192 untuk icon kecil
4. Simpan sebagai `icon-192x192.png` dan `icon-512x512.png`

### Opsi 3: AI Generator
1. Gunakan tool seperti [Favicon.io](https://favicon.io/) atau [RealFaviconGenerator](https://realfavicongenerator.net/)
2. Upload logo Anda
3. Generate dan download icon

## Catatan

- Icon akan digunakan untuk:
  - Home screen icon (Android/iOS)
  - Splash screen saat aplikasi dibuka
  - App launcher di berbagai platform
- Pastikan icon jelas dan mudah dikenali pada ukuran kecil
- Gunakan warna yang kontras dengan background
